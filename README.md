# Example Mod For Stardew Modsite
This is an example mod's repo which can utilise and document the different features that can be used for the stardew modsite, it also acts an a to do for what features still nees to be added.
tbis readme will be used at tbe mod's description on the site, however this may not be wanted, the repo readme may be used for mod authors especially in the case of framework mods, if this is the case, you can use a spoiler section anywhere in the main repo readme to redirect to another file within the repo, an example would be:
